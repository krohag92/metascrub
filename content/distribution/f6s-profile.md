## Short description (paste into "Description" or "About" field, ≤ 300 words)

MetaScrub reads and strips hidden metadata from files. Every file carries invisible information alongside its visible content — GPS coordinates in photos, author names in documents, revision histories in Word files, software identifiers in PDFs. MetaScrub makes this visible and removes it before you share.

It supports 25 formats (JPEG, PNG, PDF, DOCX, MP3, MP4, and more) and runs everywhere: web tool at metadatafinder.com, CLI (`npm install -g metascrub`), Python package, browser extension for Chrome/Firefox/Edge/Opera, VS Code extension, Obsidian plugin, n8n node, Figma plugin, Docker image, and Tauri desktop app. All local — no files leave the device.

MIT license. Source at https://github.com/metascrub/metascrub. Web tool at https://metadatafinder.com.
