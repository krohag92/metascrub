## 150 words

MetaScrub is an open-source tool for viewing and stripping file metadata. Every photo, document, audio file, and video carries hidden information alongside its content: GPS coordinates, device serial numbers, author names, editing history, and software fingerprints. Most of the time this is invisible. Sometimes it is a serious privacy or security risk.

MetaScrub supports 25 file formats — images (JPEG, PNG, HEIC, WebP, AVIF, TIFF, and RAW formats), audio (MP3, FLAC, M4A, OGG, WAV), video (MP4, MOV, MKV, WebM), and documents (PDF, DOCX, XLSX, PPTX, EPUB, SVG). It is available as a web tool at metadatafinder.com, an NPM CLI, a Python package, a browser extension (Chrome, Firefox, Edge, Opera), a VS Code extension, a Docker image, and as integrations for Obsidian, Raycast, n8n, and Figma.

All processing happens locally. No file data is ever transmitted to a server. MIT license.

More at https://metadatafinder.com.

## 300 words

MetaScrub is an open-source metadata viewer and scrubber distributed across 15+ platforms. It solves a straightforward problem: files contain hidden information that their owners often do not know is there, and that information travels with the file every time it is shared.

A photograph taken on a smartphone contains GPS coordinates accurate to a few meters, the phone model, the date and time, and sometimes the owner's name — all embedded invisibly in the EXIF data. A Word document contains the creator's name, the employer's company name (pulled from Microsoft 365 Active Directory), tracked changes from all previous editors, and comments that may have been thought deleted. A PDF contains the creating application, the author's name, and a unique document identifier that can link multiple versions of the same document.

MetaScrub reads these fields, displays them clearly, and strips them with one command. It offers four scrub presets: remove all metadata, remove GPS only, remove personal info only, or keep only technical camera data. For each operation, it can compare the before and after states to show exactly what changed.

The tool supports 25 file formats: JPEG, PNG, HEIC, WebP, AVIF, TIFF, RAW (CR2, NEF, ARW, DNG), MP3, FLAC, M4A, OGG, WAV, MP4, MOV, MKV, WebM, PDF, DOCX, XLSX, PPTX, EPUB, and SVG.

It is available as a web tool (no install, no upload — processing happens in the browser), an NPM CLI, a Python package with pandas integration, a browser extension for Chrome/Firefox/Edge/Opera, a VS Code extension, a Tauri desktop app for macOS/Windows/Linux, a Docker image with CLI and HTTP API, and plugins for Obsidian, Raycast, n8n, Figma, and WordPress.

MetaScrub is built by Anton Krokhmal and is open source under the MIT license.

More at https://metadatafinder.com.
