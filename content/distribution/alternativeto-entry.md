## Step 1 — MetaScrub product entry

**Product name:** MetaScrub

**URL:** https://metadatafinder.com

**Short description (≤ 300 chars):**

> Open-source metadata viewer and scrubber. View EXIF, GPS, ID3, XMP, and document properties inside images, audio, video, and documents. Strip them with one command. 25 formats. Web, CLI, Python, browser extension, VS Code, Docker, and more.

**Full description:**

MetaScrub is an open-source tool for viewing and stripping file metadata. Files carry hidden information their creators often do not know is there: GPS coordinates in photos, author names in documents, revision histories in Word files, software identifiers in PDFs. MetaScrub reads these fields clearly and removes them before the file is shared.

**What it does:**

- View all metadata fields: EXIF, IPTC, XMP, GPS, ID3 (audio), DOCX core/app/custom properties, PDF Info Dictionary + XMP stream, video container tags
- Strip metadata with four presets: All / GPS only / Personal only / Keep technical
- Compare metadata between two files (before/after, forensics diff)
- Batch processing for folders and multiple files
- Local processing only — files never leave your device

**Supported formats (25):**
JPEG, PNG, HEIC, WebP, AVIF, TIFF, RAW (CR2, NEF, ARW, DNG), MP3, FLAC, M4A, OGG, WAV, MP4, MOV, MKV, WebM, PDF, DOCX, XLSX, PPTX, EPUB, SVG

Web, Windows, macOS, Linux, Android [verify: confirm Android app is live before tagging], iOS [verify: confirm iOS app is live before tagging], browser extensions (Chrome, Firefox, Edge, Opera), Docker, VS Code

### Alternative to: ExifTool

**ExifTool AlternativeTo page:** https://alternativeto.net/software/exiftool/

**Comparison note (what to write in the "Why is it a good alternative?" field):**

MetaScrub offers everything ExifTool does for the most common formats, plus a web tool (no install), browser extension, Python library, VS Code extension, and GUI-friendly scrub presets. ExifTool is deeper on obscure formats and raw parsing; MetaScrub is more accessible to non-CLI users and integrates into more environments.

**What ExifTool does better:**

- Supports far more obscure formats and metadata tags than MetaScrub
- Mature, battle-tested codebase with 20+ years of fixes
- More granular control over individual tag writes

**What MetaScrub does better:**

- Web-based option — no installation required
- Browser extension for on-the-fly metadata checking
- Python library with pandas integration for data pipelines
- VS Code, Obsidian, Raycast, n8n, and Figma integrations
- More user-friendly scrub presets vs. ExifTool's command flags
- Actively maintained TypeScript codebase

**What MetaScrub does better:**

### Alternative to: PDFsam

**PDFsam AlternativeTo page:** https://alternativeto.net/software/pdfsam/

**Comparison note:**

PDFsam (PDF Split and Merge) is focused on PDF manipulation — splitting, merging, rotating pages. MetaScrub is focused on metadata: it reads and strips PDF metadata (Info Dictionary, XMP, producer/creator fields) and also handles non-PDF file types. They solve adjacent but distinct problems.

**What PDFsam does better:**

- Splitting and merging PDFs
- Page-level operations (rotate, extract, mix)
- Has a well-established community and free + paid tiers

**What MetaScrub does better:**

- Reads and strips PDF metadata fields specifically
- Handles images, audio, video, and other documents alongside PDFs
- Available as a CLI, browser extension, Python library, and more
- No PDF splitting/merging — it focuses on what's in the metadata, not the document structure
