## MetaScrub Launches as Open-Source Metadata Tool Across 15+ Platforms

_Privacy-first viewer and scrubber supports 25 file formats; available as web tool, CLI, browser extension, and more_

**[CITY], [DATE]** — MetaScrub, an open-source metadata viewer and scrubber, is now available across more than [PLATFORM_COUNT] distribution channels including the Chrome Web Store, NPM, PyPI, VS Code Marketplace, Docker Hub, and the MetaScrub web tool at metadatafinder.com.

MetaScrub addresses a widespread privacy gap: digital files carry hidden metadata — GPS coordinates, author names, editing history, and device serial numbers — that their owners often do not know is present. When these files are shared, the metadata travels with them.

"Files tell stories their creators didn't intend to tell," said Anton Krokhmal, the developer behind MetaScrub. "A photo taken at home contains the home address. A Word document contains the employer's company name and everyone who ever edited it. MetaScrub makes this visible and removes it in one step." [NOTE: confirm this quote is accurate before distribution]

MetaScrub supports 25 file formats including JPEG, PNG, HEIC, WebP, AVIF, TIFF, RAW camera formats (Canon CR2, Nikon NEF, Sony ARW, Adobe DNG), MP3, FLAC, M4A, MP4, MOV, MKV, PDF, DOCX, XLSX, PPTX, and EPUB. Metadata standards covered include EXIF, IPTC, XMP, GPS, ID3, and document properties in DOCX and PDF formats.

All file processing happens locally. No file data, metadata, or user information is transmitted to any server. The tool does not collect analytics.

**Availability**

MetaScrub is available today at:

- Web tool (no install): https://metadatafinder.com
- CLI: `npm install -g metascrub`
- Python: `pip install metascrub`
- Browser extension: Chrome Web Store, Firefox Add-ons, Microsoft Edge Add-ons, Opera Add-ons
- Developer tools: VS Code Marketplace, Obsidian Community Plugins, Raycast Store, n8n community nodes, Figma Community
- Infrastructure: Docker Hub (`metascrub/metascrub`)

MetaScrub is open source under the MIT license. Source code is available at https://github.com/metascrub/metascrub.
