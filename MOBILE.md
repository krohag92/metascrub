# Mobile — iOS + Android (Capacitor)

Single codebase using Capacitor 6, React, and `@metascrub/core`. Ships to App Store and Google Play with the same UI.

## Why Capacitor (not React Native or native)

- We already have a TypeScript core — reusing it is trivial in Capacitor's WebView.
- Share Extensions / Intents on both platforms via standard Capacitor plugins.
- App Store + Google Play accept Capacitor apps as long as they have native value (which we have: Share extension, file system access).

## Goals

- Open a file from anywhere on the device → see metadata → scrub → save back.
- Integrate with Share Sheet (iOS) and Share Intent (Android): "Share to MetaScrub" from Photos, Files, etc.
- Optional bulk-scrub from a folder.
- No analytics. No network calls. All client-side.

## capacitor.config.ts

```typescript
import type { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId: 'com.metadatafinder.metascrub',
  appName: 'MetaScrub',
  webDir: 'dist',
  plugins: {
    Filesystem: {},
    Share: {}
  }
};

export default config;
```

## Plugins

- `@capacitor/filesystem` — read/write files
- `@capacitor/share` — share cleaned file back out
- `@capacitor-community/share-target` (or custom share extension on iOS) — receive files from Share Sheet / Intent
- `@capacitor/preferences` — settings storage

## iOS Share Extension

Capacitor doesn't ship a Share Extension out of the box. Add one manually in Xcode:

1. File → New → Target → Share Extension.
2. Configure `NSExtensionActivationRule` to accept images, videos, PDFs, documents.
3. Forward the shared file URL into the main app via App Group + UserDefaults, then open the app with a custom URL scheme `metascrub://share?path=...`.
4. In `App.tsx`, listen for `App.addListener('appUrlOpen', ...)` and route to FileScreen.

This is the most complex native bit. Allocate time.

## Android Share Intent

Add to `AndroidManifest.xml`:

```xml
<intent-filter>
  <action android:name="android.intent.action.SEND" />
  <category android:name="android.intent.category.DEFAULT" />
  <data android:mimeType="*/*" />
</intent-filter>
<intent-filter>
  <action android:name="android.intent.action.SEND_MULTIPLE" />
  <category android:name="android.intent.category.DEFAULT" />
  <data android:mimeType="*/*" />
</intent-filter>
```

Use `@capacitor/app` `appUrlOpen` event or a small custom plugin to extract the shared file URI(s).

## UX flow

1. **Home** — recently processed files (local only), "Pick a file" button, "Or share to MetaScrub from any app" tip.
2. **File screen** — shows file thumbnail, format, size, captured-at, warnings at top, full metadata grouped below.
3. **Scrub screen** — preset picker (radio list), preview of "what will be removed", Scrub button.
4. **Result** — "Saved to Files" / "Share cleaned copy" buttons.
5. **Settings** — default preset, "Open on metadatafinder.com" link.

Same approach: "No data collected", "No data shared", "Data is processed on-device".

## In-app review prompt

After 3 successful scrubs, prompt for App Store / Play Store review. Use `@capacitor-community/in-app-review`.

## Build & sign

Bullet points for Claude Code:
- Maintain `.env.production` with bundle ID, signing identifiers.
- `pnpm build && npx cap sync` before each native build.
- iOS: archive in Xcode, upload via Transporter.
- Android: `gradle bundleRelease`, upload `.aab` to Play Console.
- Keep keystore in 1Password or similar — never commit.
