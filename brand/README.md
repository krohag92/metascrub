# MetaScrub brand kit

Logo, colour tokens, and the icon generator for **MetaScrub** / **Metadata Finder**.

Home: [https://metadatafinder.com](https://metadatafinder.com)

Tagline: "See and strip metadata from any file"

## Files

| Path                | What it is                                                                             |
| ------------------- | -------------------------------------------------------------------------------------- |
| `logo/mark.svg`     | App mark. Square, drawn on a 16px grid so the toolbar icon stays legible.              |
| `logo/wordmark.svg` | Mark plus "MetaScrub" and "Metadata Finder". Regenerated by the icon script.           |
| `tokens.json`       | Colour and type tokens. Source of truth.                                               |
| `tokens.css`        | The same colours as CSS variables.                                                     |
| `dist/`             | Rendered PNG, ICO, ICNS, and store tiles. Safe to commit; regenerate rather than edit. |

The mark is a photo viewfinder (white corners) with a green lens on the navy tile from the press kit: `#0F172A` and `#22C55E`.

## Generate icons

From the repo root:

```bash
pnpm brand:icons
```

That rasterises `logo/mark.svg` with [sharp](https://sharp.pixelplumbing.com/) (Apache-2.0) and writes every size the packages already ship. Requires the system font **Inter** (or Liberation Sans) for the wordmark and store tiles. No extra design tools.

### Sizes

| Destination                                         | Sizes                                                                                                                         |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `packages/extension` (Chrome, Edge, Opera, Firefox) | 16, 32, 48, 128                                                                                                               |
| `packages/vscode`                                   | 128 (`icon.png`), 256 (`icon-256.png`)                                                                                        |
| `packages/raycast`                                  | 512                                                                                                                           |
| `packages/obsidian`                                 | 256 (`icon.png`)                                                                                                              |
| `packages/figma`                                    | 128 (`icon.png`)                                                                                                              |
| `packages/n8n-node`                                 | `metascrub.svg` (the mark)                                                                                                    |
| `packages/desktop` Tauri                            | 16–1024 PNG, `icon.ico`, `icon.icns`, plus `public/icons/32x32.png`                                                           |
| `packages/mobile` Capacitor                         | PWA 16/32/48/128/192/512, Apple touch 180, favicon, iOS icon set, Android mipmaps (launcher, adaptive background, foreground) |
| `brand/dist/store`                                  | Chrome small tile 440×280, marquee 1400×560, social preview 1280×640                                                          |

iOS icons are square (the OS masks them). Android adaptive foregrounds keep the artwork in the centre safe zone on a transparent canvas. Everything else uses the rounded mark.

## Change the logo

1. Edit `logo/mark.svg`. Keep the viewBox at `0 0 16 16` and the navy/green token hex values.
2. Run `pnpm brand:icons`.
3. Commit the SVG and the regenerated files, including `dist/manifest.json`.

`pnpm --filter @metascrub/brand test` checks that those files exist, have the right pixel dimensions, and are not flat colour placeholders.
