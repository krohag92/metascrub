## 300 words

Anton Krokhmal is a developer, SEO practitioner, and privacy tools builder based in Ukraine. He created MetaScrub — an open-source metadata viewer and scrubber for images, audio, video, and documents — and distributes it across 15+ platforms.

The project started from a recurring professional observation: files shared in ordinary workflows contain metadata that their creators did not intend to share. Photos from client shoots contain GPS coordinates pointing at home addresses. Word documents contain company names and revision histories from employees who do not know those fields exist. PDFs carry the name of whoever created them and unique identifiers that can link document versions across organizations.

MetaScrub addresses this across every environment where people work with files: a web tool that processes files entirely in the browser, an NPM CLI for terminal users and scripting, a Python package for data engineering pipelines, a browser extension for Chrome/Firefox/Edge/Opera, a VS Code extension, a Tauri desktop app for macOS/Windows/Linux, a Docker image with an HTTP API for self-hosted infrastructure, and plugins for Obsidian, Raycast, n8n, Figma, and WordPress.

The multi-platform approach is deliberate: the same metadata problem appears across contexts, and the tool needs to be accessible in each of them. A lawyer needs a web tool they can use without installing anything. A developer processing documents in Python needs a library. A journalist checking photos in the field needs a mobile app.

Professionally, Anton is SEO Team Lead at Skelar, where he leads growth strategy for SaaS products, and AI Operations Lead, applying large language models to content and research workflows.

Anton builds in public. Ongoing project updates are at metadatafinder.com, and he can be reached through antonkrokhmal.com or via krohag92@gmail.com.
