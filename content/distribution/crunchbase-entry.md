## Long description (150-200 words — paste into "Description" field)

MetaScrub is an open-source privacy tool for viewing and stripping metadata from files. Hidden metadata travels with every file: GPS coordinates in photos, author names in documents, editing histories in Word files, software identifiers in PDFs. MetaScrub reads these fields clearly and removes them before the file is shared.

The tool supports 25 file formats across images (JPEG, PNG, HEIC, WebP, AVIF, TIFF, RAW), audio (MP3, FLAC, M4A, OGG, WAV), video (MP4, MOV, MKV, WebM), and documents (PDF, DOCX, XLSX, PPTX, EPUB, SVG).

MetaScrub is distributed across 15+ platforms from a single open-source TypeScript core: a web tool at metadatafinder.com, an NPM CLI, a Python package with pandas integration, browser extensions for Chrome/Firefox/Edge/Opera, a VS Code extension, a Tauri desktop app, a Docker image with HTTP API, and plugins for Obsidian, Raycast, n8n, Figma, and WordPress. All file processing happens locally — no files are uploaded to any server.

Built by Anton Krokhmal. MIT license. https://metadatafinder.com
